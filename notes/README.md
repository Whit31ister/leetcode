## How to Use These Notes

1. Identify the input shape and constraints.
2. Choose the simplest pattern that meets the time and space limits.
3. Write the invariant before implementing the loop.
4. Test empty input, one element, duplicates, negative values, and boundary values.
5. Record the final time and space complexity.

## Complexity Quick Reference

| Operation | Typical complexity |
|---|---:|
| Array index access | $O(1)$ |
| Binary search | $O(\log n)$ |
| Hash table lookup | $O(1)$ average |
| Balanced tree lookup | $O(\log n)$ |
| Comparison sorting | $O(n \log n)$ |
| BFS or DFS on a graph | $O(V + E)$ |
