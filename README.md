# Leetcode Solutions

Repository for tracking and recording Leetcode problem solutions implemented in Python.

## Overview

This repository contains solutions to Leetcode problems organized by topic. Each solution includes the problem implementation and is named with the problem number and title for easy reference.

## Directory Structure

- **Array/** - Array and list manipulation problems
  - Problems like 3Sum, 4Sum, duplicate removal, missing numbers, and duplicate detection
  - Covers array searching, sorting, and element manipulation techniques

- **notes/** - Algorithm documentation and complexity analysis
  - Big O complexity explanations and examples
  - Reference material for algorithm analysis and performance considerations

- **test.py** - General testing file for validating solutions

- **README.md** - Documentation and repository overview

## File Naming Convention

Solution files follow the format: `[problem_number] [problem_title].py`

Examples:
- `15 3sums.py` - Leetcode problem 15 (3Sum)
- `268 Missing number.py` - Leetcode problem 268 (Missing Number)
- `271 Contains duplicate.py` - Leetcode problem 271 (Contains Duplicate)

## Usage

Each Python file contains a self-contained solution. Files can be run directly or imported for reference. The notes folder provides supporting material for understanding algorithm complexity and performance.

## Purpose

This repository serves as a personal learning resource and reference for Leetcode problems solved, helping track progress and maintain a searchable collection of solutions by problem category and number.
